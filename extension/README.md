# Agent Tour

Guided, spotlighted tours of agent-written changes, played in the real VS Code editor.
Each step highlights the lines that matter, dims the rest, and shows a card with what
changed, why, and what to watch for.

- **Green**: change. **Blue**: context. **Amber**: decision (your judgement is needed).
  **Red**: risk.
- `Alt+]` next, `Alt+[` previous, `Alt+H` show the card again, `Esc` stop.
- Tours are published by the `code-tour` skill for Claude Code into a per-user temp folder,
  never into your repository.

Documentation, the skill download and source code: https://github.com/SuryanshBVerma/agent-tour
